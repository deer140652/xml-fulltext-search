系統運作原理

  1. 文件擷取：支援上傳 XML 或透過 PMID 取得文獻。自動辨識 PubMed / JATS 格式，擷取標題與摘要；其他 XML 則擷取全文文字。
  2. 句子分割：採規則式斷句切分文本，正確處理縮寫與小數點，避免誤判句尾。
  3. 文字正規化：統一大小寫、移除停用詞，並使用 Porter 詞幹還原。連字號複合詞同時保留完整詞形與拆分詞，提升搜尋涵蓋率。
  4. 索引建置：建立「摘要」與「標題＋摘要」兩套加權反向索引，依「包含標題」選項切換。文件新增後，瀏覽器即時重建索引。
  5. 向量檢索：以詞幹還原及餘弦相似度進行文獻排序，並支援 * 前綴搜尋。

提示：字尾加 * 可進行前綴搜尋
